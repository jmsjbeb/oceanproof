# Validation Plan — OceanProof (海证)

**Project:** OceanProof · AI4Climate Global Youth Climate Solutions Challenge 2026
**Track:** Open Track

---

## 1. Target users

| User group | Who they are | What they need from the tool |
|---|---|---|
| **Coastal fishers and aquaculture households** (primary) | Small-scale operators in Zhejiang, Fujian, Shandong; ~1–2 million households nationally | Whether their catch area is affected, when, and whether consumer avoidance is already hitting their orders |
| **Inland urban residents** (secondary) | Consumers in cities such as Chengdu, Xi'an, Wuhan who ask "is the fish I buy safe" | A magnitude-based answer, not a headline |
| **Local fishery cooperatives and market managers** | Cooperatives, wholesale market operators | A defensible reference when responding to members' and buyers' questions |
| **Science communicators and educators** | Museums, schools, science centres | A visual, provenance-tagged explainer for public engagement |

## 2. Pilot setting

**Location:** one coastal county-level district with an active fishery economy plus one inland city, both reachable within the partner network (target: Xiangshan County, Ningbo, Zhejiang + Chengdu, Sichuan as the inland control).

**Duration:** 90 days.

**Form:** lightweight, no app installation — the tool is a static web page opened on a phone or a cooperative's shared tablet; printed one-page "ledger cards" for households without reliable connectivity.

## 3. Test method

**Phase 1 — comprehension test (weeks 1–3).** 15–20 users (10 fishers/aquaculture households, 5 residents, 3–5 cooperative staff). Task-based: each participant answers three questions using the tool — *when does it arrive, how long does it last, can I still eat the fish*. Measured: task completion rate, time on task, and whether the participant can restate the answer in their own words.

**Phase 2 — decision-use test (weeks 4–8).** Users keep a simple log for four weeks: did the tool change a decision (fishing area, market messaging, purchase)? Each entry is one line, collected via a paper card or a messaging group.

**Phase 3 — trust calibration (weeks 9–12).** Compare two versions of the same answer: one presented as a single number, one as a magnitude range with provenance tags. Measure which version users over-trust less (i.e. whether they correctly report "this is an estimate").

## 4. Success criteria

| Metric | Target |
|---|---|
| Task completion (three questions answered unaided) | ≥ 80% of participants |
| Correct restatement of the answer | ≥ 70% |
| Median time to answer | ≤ 3 minutes |
| Users reporting at least one decision influenced | ≥ 30% |
| Users correctly identifying the answer as an estimate rather than a measurement | ≥ 60% (magnitude-range version) |
| Reported trust in the tool (5-point scale) | ≥ 3.5 average, with no "it tells me it's safe to eat" over-claim |

## 5. Feedback loop

Every round produces a short written log (what users asked, what they misunderstood, which screen they abandoned). Interface changes are batched weekly and re-tested with the same participants where possible. Two specific items are expected to change as a result: the wording of the food-safety card, and the prominence of the "screening-level, not early-warning" boundary statement.

## 6. What we will not claim

The pilot measures **comprehension, trust calibration and decision-use**, not health outcomes. We will not present the tool as a food-safety authority, and we will not use pilot results to claim that any specific fishery is safe or unsafe.
